# 删除主机与新发送端配对回归修复

2026-11-16。本轮交付为 ZIP 测试包，未重新制作安装程序。

## 已确认的代码缺陷

1. GUI 与 ReceiverService 曾各自创建 ComputerManager，并各自把完整 hosts 数组写入同一个 QSettings。两份缓存会覆盖删除结果或新配对证书。现共用 GUI 的单例管理器；删除、刷新、配对使用同一份主机表。
2. 新主机路径停在 AddingHost，成功的 pairingCompleted 没有被 PairingHost 分支处理。现明确转换，并按请求地址和实际 HTTP 返回的主机对象关联结果。
3. 验证旧证书失败/超时后继续串流，会让子进程弹“尚未配对”。现失败返回 412，不启动串流；成功后等待 hosts 落盘，并比对当前 UUID 与证书 DER。
4. Sunshine 重装改变 UUID 时，按 IP 启动可命中同地址旧记录。现每次刷新实际主机，串流按其 UUID 启动。
5. 发送端手动添加已存在 IP 原先直接返回。现更新端口并重新 GET /state；旧端口的在途回复不会覆盖新端口。
6. 普通 Moonlight GUI 原先不启动待机服务。现普通界面和 standby --ui 都启动服务；串流 CLI 不启动。普通界面可手动连员工主机，不能用来证明旧版待机端口在监听。

7. 发送端原 cast 超时为 15 秒，短于接收端发现 20 秒 + 配对最多 20 秒的预算。现为 45 秒，避免成功握手之前发送端已经提示超时。本改动已重编进 v2 ZIP。

删除主机的调用本身没有关闭 UDP/TCP 的路径。因此不能仅凭现象认定“删除动作关闭服务”；用户现场旧日志缺少本次失败时间，需要新包复测确认。

## 并发与生命周期

主机表快照加读锁，避免异步删除与序列化竞争。配对任务持有主机生命周期租约：GUI 删除延后到结果交付后；拒绝同记录的并发配对。超时或取消只结束请求，不假定后台 worker 已结束；worker 未回收前不接受新 cast，晚到结果不能启动下一次投屏。手动添加结果在主线程验证指针仍有效后再交付。

## 验收步骤

两台机器均关闭旧版后替换测试目录中的程序。不要同时运行旧待机实例；保留现有配置与证书，无需删除注册表。

1. 大屏启动接收端，员工自动发现；手动添加大屏 IP 也应成功。
2. 在大屏删除员工主机，员工仍应发现大屏；再次手动添加同一个 IP 必须重新探测。
3. 员工点击投屏：大屏自动刷新当前 UUID、握手、落盘，再拉起串流。不得出现人工 PIN 或“尚未配对”。
4. 新装/重建 Sunshine 状态后重测：即使保留大屏旧记录，也必须使用新 UUID。
5. 人为关闭发送端或使握手失败：接收端返回明确失败且不启动串流；恢复后可重试。

HTTP 200 和 /state 的 streaming 仍只表示串流进程已启动，真实画面需现场确认。不能把模拟/注入的配对成功当作真实协议握手或两机视频验收。

测试入口为 moonlight/tests/receiver-regression/run.ps1。它链接真实 ReceiverService / ComputerManager，使用隔离 INI、回环临时端口和替代串流子进程；不联系员工电脑、不更改正式证书。成功握手完成事件由测试注入；失败握手 worker、持久化、子进程参数与删除操作执行真实代码。

首轮最终结果：30 项断言通过，UDP 发现断言失败，整个测试退出码为 1。通过项包含真实失败握手不拉流、超时/取消/晚到结果、精确 UUID/证书落盘和子进程参数、异步删除后 HTTP、配对中的延后删除及重复配对拒绝。证据 artifacts/receiver-regression/final-result.log:95。

加入删除前基线的补充测试：原生程序完成 33 项断言，包含删除后 UDP 请求和响应内容，以及全部任务租约测试（artifacts/receiver-regression/baseline-result.log:95-98）。但删除前基线 reply=false（同日志:63-64），说明 UDP 存在时序/环境间歇性，不能声称其根因已查明。外层 PowerShell 日志管道因 qInfo 写 stderr 被包装成 NativeCommandError 而退出 1；应区分原生程序断言结果与包装脚本退出码，不把整套命令描述为全绿。

独立 PowerShell/.NET UdpClient 对照（不运行接收端代码）同样在发送到 127.0.0.1 后 Receive 超时；结合补充测试中删除后的回包成功，目前只能判断 UDP 存在间歇性或时序影响，根因尚未定位。删除后回环发现已获得一次通过证据，但不能据此证明真实局域网发现稳定恢复。未调整防火墙或扩大授权范围。两机发现与真实成功握手/画面仍待验收。
